# Three-minute recruiter demo

1. Open the app. If you see **Starting demo service**, click **Wake Demo** and wait.
2. Go to **Try Demo**. Read the warning: do not submit personal data.
3. Run a **Sample scenario** (labelled **Deterministic demo**). These are not live AI responses.
4. Watch **Queued → Processing → Completed** on the same page. Intelligence opens automatically.
5. Confirm extracted employee, related-case evidence, and stakeholder routing.
6. Optionally submit a **Custom case**. If Live AI is configured (`LLM_MODE=live`), that path is labelled **Live AI** and uses the same pipeline with Gemini.

Inbound email is optional: copy the temporary `case-<token>@<domain>` address only when Resend is configured.
