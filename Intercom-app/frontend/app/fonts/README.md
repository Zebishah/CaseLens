# Local product fonts

Manrope (weights 200–800) is the interface and body family. Sora (weights 100–800) is the heading and display family. Both are variable fonts loaded through `next/font/local`; visitors do not contact a third-party font service.

Original, unmodified distributions:

- Manrope: https://github.com/google/fonts/tree/main/ofl/manrope
- Sora: https://github.com/google/fonts/tree/main/ofl/sora

The corresponding SIL Open Font License files are included beside each font. Keep them with any redistributed font files.
